# VampireUHC - Version compatible 26.2

Cette version de **VampireUHC** est la version originelle, créée pour MineCraft `26.2`.

## Prérequis

Vous aurez besoin de [`Java 25 ou +`](https://www.oracle.com/fr/java/technologies/downloads/) et [gradle](https://gradle.org/).

## Quickstart

Pour l'utiliser, veuillez d'abord cloner le repo et vous rendre à la racine de cette version du plugin :

```bash
git clone https://github.com/VRAM-RAM/VampireUHC
cd 26.2/
```

Ensuite, compilez le plugin à l'aide de `gradle` :
```
./gradlew clean build
```

Vous trouverez le plugin à `/26.2/build/libs/vampire-uhc-1.0.0.jar`.
